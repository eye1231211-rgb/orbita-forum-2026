## Готовый Node-комплект

`orbita-runtime.zip` содержит уже собранный интерфейс, сервер, демоданные, миграции и конфигурацию Docker/Caddy. Для обычного запуска нужны только Node.js 24 и постоянная папка с правом записи. npm и доступ к OpenAI/Cloudflare при запуске не нужны. В архиве нет рабочей SQLite-базы, сессий, .env с ключами или node_modules.

1. Распаковать ZIP в отдельную папку.
2. На Windows открыть `start.cmd`; на Linux выполнить `node scripts/portable-server.mjs` из этой папки.
3. Открыть http://127.0.0.1:3000/login. Остановка сервера - Ctrl+C.
4. Первая загрузка создаст `data/orbita.sqlite` и добавит вымышленные записи. При следующих запусках заявки и отметки сохраняются. При смене версии сохранять папку data.

Тестовые профили: `alina` и `mark`. Пароли передаются жюри в комментарии к работе. В обращениях используйте вымышленные данные.

Повторная сборка из исходников: `npm ci`, `npm run portable:build`, затем `python scripts/package-portable.py --output <путь-к-ZIP>`. После пересборки перезапустить Node-сервер: он читает index.html при старте. Старые D1-записи и локальная SQLite - отдельные хранилища; перенос существующих D1-заявок в ZIP не выполнялся.

## Сервер с HTTPS

Подойдёт Linux VPS с постоянным диском, Docker Compose, публичным IP и доменом. Стартовая конфигурация для ограниченной конкурсной демонстрации - 1 vCPU и 1-2 GB RAM; нагрузочные пределы не измерялись. Выбранного и оплаченного тарифа нет. Предпочтителен сервер в доступной российской сети без обязательного CDN Cloudflare.

1. Направить домен на сервер и обеспечить входящие HTTP/HTTPS на 80/443.
2. Загрузить распакованный runtime комплект на сервер.
3. Скопировать `deploy/.env.example` в `deploy/.env`, задать `ORBIT_DOMAIN` равным своему домену без https:// и пути.
4. Из папки комплекта выполнить `docker compose --env-file deploy/.env -f deploy/compose.yaml up -d --build`.
5. Caddy выдаёт HTTPS и проксирует запросы в Node. Порт Node наружу не опубликован. PUBLIC_ORIGIN задаётся точным HTTPS origin домена; сервер не доверяет произвольному Host и forwarded headers.
6. Убедиться, что оба аккаунта входят, созданная заявка сохраняется после перезапуска, чужой ID недоступен. Проверить новую ссылку из домашней и мобильной сетей без VPN.

Подключение к системам РЭУ задаётся теми же переменными окружения процесса: `ORBIT_IDENTITY=oidc` с ключами единого входа и `ORBIT_GRADES=university` с адресом и токеном ведомости. Полный перечень — в `.env.example` в корне исходников, контракт для ИТ-службы вуза — в `docs/ПОДКЛЮЧЕНИЕ-РЭУ.md`. Без этих переменных портал работает на демонстрационных данных, а расписание всё равно живое: оно идёт с публичного экспорта rasp.rea.ru и настроек не требует.

SQLite, включая WAL, хранится в volume orbit-data; сертификаты - в отдельных Caddy volumes. Смена контейнера не должна удалять эти volumes. Резервное копирование и контроль доступности до 2026-11-28 - эксплуатационная задача владельца сервера.
